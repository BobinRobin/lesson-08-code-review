# Формат данных

Модель ожидает CSV файл со следующими столбцами:

pickup_datetime - дата и время посадки (формат: YYYY-MM-DD HH:MM:SS)

fare_amount - стоимость поездки (целевая переменная)

passenger_count - количество пассажиров

pickup_longitude, pickup_latitude - координаты посадки

dropoff_longitude, dropoff_latitude - координаты высадки

# 5. Архитектура модели
Алгоритм
Алгоритм: Gradient Boosting Regressor из библиотеки scikit-learn

Особенности: Использование временных признаков (час, день недели) и евклидова расстояния

Воспроизводимость: Фиксированный random_state=42 для всех случайных операций

Гиперпараметры: Настраиваемые через конфигурационный файл

Метрики качества
Модель оценивается с помощью следующих метрик:

R² (коэффициент детерминации) - основная метрика, диапазон от -∞ до 1

MSE (среднеквадратичная ошибка)

RMSE (корень из среднеквадратичной ошибки)

MAE (средняя абсолютная ошибка)

MAPE (средняя абсолютная процентная ошибка)

Все метрики сохраняются в файл models/metrics.json для последующего анализа.

# 6. Комплексное тестирование
Проект включает комплексные тесты, соответствующие лучшим практикам тестирования в машинном обучении.

Особенности тестирования
Фикстуры (conftest.py) - предопределенные наборы данных для тестов

Параметризованные тесты - тестирование граничных случаев с использованием декоратора @pytest.mark.parametrize

Mock-объекты - изоляция тестов от внешних зависимостей (файловая система, логгирование, библиотеки)

Тесты логгирования - проверка корректности логирования операций

Воспроизводимость - фиксированные seed для детерминированных тестов
