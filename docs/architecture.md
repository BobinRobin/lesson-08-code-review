
## **Архитектура проекта**


## Обзор архитектуры

Проект реализует классический ML пайплайн для регрессионной задачи предсказания стоимости поездок такси. Архитектура спроектирована с учетом принципов модульности, тестируемости и воспроизводимости.

```text
lesson-08-code-review/
├── src/                           # Исходный код
│   ├── __init__.py
│   ├── data/                      # Модуль работы с данными
│   │   ├── __init__.py
│   │   ├── ingestion.py           # Загрузка данных
│   │   └── preprocessing.py       # Предобработка данных
│   ├── features/                  # Модуль создания признаков
│   │   ├── __init__.py
│   │   └── engineering.py         # Извлечение временных признаков
│   ├── models/                    # Модуль моделей
│   │   ├── __init__.py
│   │   ├── training.py            # Обучение модели
│   │   └── evaluation.py          # Оценка модели
│   └── utils/                     # Утилиты
│       ├── __init__.py
│       ├── config.py              # Загрузка конфигурации
│       └── logger.py              # Настройка логгирования

│   ├── __init__.py
│   ├── conftest.py                # Фикстуры для всех тестов

├── run_tests.py                   # Скрипт запуска тестов
```
