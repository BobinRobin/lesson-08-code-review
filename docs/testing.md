
## **Тестирование**

Проект включает комплексную систему тестирования, соответствующую лучшим практикам тестирования в машинном обучении.

## Обзор тестирования

### Статистика тестов

- **Всего тестов**: 37
- **Покрытие кода**: 88%
- **Время выполнения**: ~1.2 секунды
- **Успешных тестов**: 100%

### Типы тестов
```text
| Тип теста | Количество | Описание |
|-----------|------------|----------|
| Юнит-тесты | 25+ | Тестирование отдельных функций и методов |
| Интеграционные тесты | 5+ | Тестирование взаимодействия модулей |
| Тесты с mock-объектами | 8+ | Изоляция от внешних зависимостей |
| Параметризованные тесты | 5+ | Тестирование граничных случаев |
| Тесты логгирования | 2+ | Проверка корректности логирования |
```

## Запуск тестов

### Базовый запуск

# Запуск всех тестов
```bash
python -m pytest tests/ -v
```
# Сокращенный вывод ошибок
```bash
python -m pytest tests/ -v --tb=short
```
